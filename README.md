# Caffè Nina - TPF React

Migración del sitio de Caffè Nina (HTML y CSS) a React con componentes reutilizables.

## Tecnologías
- React + Vite
- React Router
- CSS

## Cómo ejecutar el proyecto localmente

1. Clonar el repositorio:
   git clone URL_DE_TU_REPO
2. Entrar a la carpeta:
   cd caffe-nina-react
3. Instalar las dependencias:
   npm install
4. Iniciar el servidor de desarrollo:
   npm run dev
5. Abrir en el navegador: http://localhost:5173/

## Estructura
- src/components: Navbar, Footer, Layout, Card, Gallery y Contact
- src/pages: Home
- src/styles: estilos CSS
- src/assets: imágenes
